# Contributing to Accounttill

Thank you for considering contributing to Accounttill! We welcome your input to improve the project.

## How to Contribute

- **Fork the repository** and create a new branch for your changes.
- **Commit** your changes with clear messages explaining what you did.
- **Push** your branch to your fork on GitHub.
- **Open a Pull Request** describing your changes. Reference any related issue number if applicable.

## Reporting Bugs

- Search existing issues to check if your bug is already reported.
- If not, open a new issue detailing:
  - Steps to reproduce the bug
  - What you expected to happen
  - What actually happened
  - Any screenshots or error messages

## Suggesting Features

- If you have an idea for a new feature, search issues to see if it’s been suggested.
- If not, open a new issue explaining:
  - The feature and its purpose
  - Why it’d be useful
  - Example use cases

## Coding Standards

- Follow the coding style used in the project.
- Test your changes before submitting them.
- Write clear, descriptive comments for complex code.

## Community Guidelines

- Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

---

If you’re unsure or need help, feel free to open an issue or ask in our community discussions.

Thanks for being part of Accounttill!
