## Key Features
- Secure user authentication (JWT & Google Auth)
- CRUD operations (Create, Read, Update, Delete)
- Clean and modern UI
- RESTful API backend
- Responsive design for all devices
- Role-based access control
- Real-time data updates
- PDF or email generation support (optional)

## Technologies used
This project was created using the following technologies.

#### Client
- React JS  
- Redux (for state management)  
- React Router DOM (for routing)  
- Axios (for API calls)  
- Material UI / Tailwind CSS (for UI design)  
- Cloudinary (for image uploads)  
- Chart.js or Apex Charts (for data visualization)

#### Server
- Express.js  
- Node.js  
- Mongoose  
- JWT (for authentication)  
- bcryptjs (for password hashing)  
- Nodemailer (for sending emails)  
- html-pdf or Puppeteer (for generating PDFs)

#### Database
MongoDB (Atlas or Local)
